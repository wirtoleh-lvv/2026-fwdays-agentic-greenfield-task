Backbone principle

AI proposes. The user reviews, confirms, resolves duplicate risk, and only then saves. No extracted candidate becomes a Library Book automatically.

MVP boundary

No accounts, cloud sync, sharing, recommendations, barcode scanning, advanced analytics, or permanent raw-photo storage are included in this map.
