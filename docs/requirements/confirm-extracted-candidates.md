# Confirm Extracted Candidates

| ID | Requirement | Status | Verification |
| --- | --- | --- | --- |
| FR-CONFIRM-001 | The Confirmation Screen displays each extracted candidate for review. | accepted | untested |
| FR-CONFIRM-002 | The user can edit candidate book information before confirmation. | accepted | untested |
| FR-CONFIRM-003 | The user can confirm a candidate for saving. | accepted | untested |
| FR-CONFIRM-004 | The user can skip a candidate so it is not saved. | accepted | untested |
| FR-CONFIRM-005 | The user can manually add an editable candidate when extraction misses a book or is unavailable. | accepted | untested |
| FR-CONFIRM-006 | Only candidates explicitly confirmed by the user are eligible to be saved. | accepted | untested |
| FR-CONFIRM-007 | A candidate with missing or uncertain information is marked Needs Review; otherwise it is marked Ready for Confirmation. | accepted | untested |
