# Duplicate Detection

| ID | Requirement | Status | Verification |
| --- | --- | --- | --- |
| FR-DUP-001 | Before saving, each confirmed candidate is compared with Library Books using normalized book information. | accepted | untested |
| FR-DUP-002 | A matching existing Library Book is identified as a Duplicate. | accepted | untested |
| FR-DUP-003 | A candidate similar to an existing Library Book is identified as a Possible Duplicate. | accepted | untested |
| FR-DUP-004 | A Duplicate Warning identifies the candidate and matching Library Book before persistence. | accepted | untested |
| FR-DUP-005 | A Duplicate or Possible Duplicate is not added silently; the user must review the warning before saving continues. | accepted | untested |
